# 📚 AI Book Finder (대구 & 영남대 도서관 / 교보문고 / 알라딘 통합 검색 및 AI 추천)

대구 지역 공공도서관, 영남대학교 도서관, 교보문고, 알라딘 온·오프라인 중고매장(대구 동성로점, 상인점)의 도서 소장 및 재고 현황을 한 번에 검색하고, AI를 통해 상황/기분별 맞춤 도서를 추천받는 웹 서비스입니다.

---

## ✨ 주요 기능

1. **5대 채널 실시간 통합 검색**
   - 🏛️ **대구광역시 통합도서관**: 대구시 내 시립 및 구·군립 공공도서관 실시간 소장 및 대출 가능 여부
   - 🎓 **영남대학교 중앙도서관**: 소장 위치(중앙도서관, 과학도서관 등), 청구기호, 대출 가능 여부
   - 🏪 **알라딘 중고매장 (대구)**: 대구 동성로점, 대구 상인점 오프라인 중고 도서 재고
   - 📖 **교보문고**: 온/오프라인(대구점, 칠곡점) 재고 및 판매가
   - 📦 **알라딘 온라인**: 온라인 새책 판매가 및 도서 상세 정보

2. **🤖 AI 도서 추천 & 즉시 재고 연동**
   - "인간관계에 지쳤을 때 읽기 좋은 책", "비전공자용 파이썬 입문서" 등 자연어 입력 지원
   - AI가 추천한 책을 클릭 한 번으로 대구/영남대 도서관 및 서점 재고 실시간 조회 연동

3. **⚡ 병렬 비동기 검색**
   - ThreadPoolExecutor 기반으로 5개 채널을 동시에 검색하여 빠른 응답 속도 제공

## 🚀 실행 방법

### 1. 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. 웹 애플리케이션 실행
```bash
streamlit run app.py
```
브라우저에서 `http://localhost:8501` 주소로 자동 접속됩니다.

---

## ⚙️ 설정 안내 (선택 사항)

웹 UI 좌측 사이드바에서 직접 설정하거나 `.env` 파일 / 환경 변수로 지정할 수 있습니다:
- `ALADIN_TTBKEY`: 알라딘 OpenAPI TTB Key (미입력 시에도 크롤링 엔진으로 자동 조회)
- `GEMINI_API_KEY`: Google Gemini API Key (미입력 시 내장 큐레이션 엔진으로 동작)
